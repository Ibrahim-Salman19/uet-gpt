## 2. Current architecture (actual flow)

See `ARCHITECTURE.md` for the full discovery → answer diagram. Key points:

- **Two crawl paths, one live.** Path A (LIVE): `scripts/crawler.py` (curl_cffi + trafilatura + pymupdf4llm) → `POST /ingest` (Bearer `CONVEX_AUTH_TOKEN`). Path B (DISABLED): Convex `executeCrawlJob` → external Crawl4AI → HMAC `/api/webhook/crawl`; its cron is commented out (`convex/crons.ts`).
- **Chunking:** hierarchical parent (3000 chars) / child (800 chars), header-aware, sentence-aware, table-aware (`convex/crawl/chunking.ts`).
- **Embedding:** `gemini-embedding-2`, 768-dim, multi-key rotation (`convex/embeddings/generate.ts`). Vectors live in the `@convex-dev/rag` component (opaque), not in user-schema tables.
- **Contextualization:** `gemini-2.0-flash` (DEAD) generates `contextualizedText`, stored on `crawledChunks`, used as the LLM's source content at generation time via `pickBestContent` (`search.ts:127`) — but **never re-embedded**, so it cannot improve recall.
- **Retrieval:** hybrid vector + 2× BM25 (`crawledChunks.text`) + FAQ (`faqs.question`), RRF fusion k=60 with IDF-adaptive weights (`search.ts`). Rerank cascade: word-overlap → optional external → Groq LLM (`llama-3.1-8b-instant`, DYING) → optional Cohere (`rerank-english-v3.0`, English-only) → positional fallback.
- **CRAG:** triggers when top rerank score < 0.6; high-confidence all-irrelevant (≥0.7) → refuse tier.
- **Answer generation:** Next.js route (`src/app/api/chat/route.ts`) → `pipeline.ts` `streamText`. Default model Groq `llama-3.3-70b-versatile` (DYING) with 6-model fallback chain. `@convex-dev/agent` registered but used **only** for thread/message storage (no `createAgent`).

## 5. Gap analysis (full severity per gap)

- **Affected:** all quality claims.
- **Root cause:** Python harness auth mismatch + degenerate golden set.
- **Proposed fix:** Phase 1 — route harness through internal `runEvalWithDataset` action (no Clerk gate) via `npx convex run`; replace substring scorer with graded qrels; deterministic fixture canaries.
- **Implemented:** NO (Phase 0A is read-only).
- **Remaining risk:** until Phase 1+2 land, every quality statement is opinion.

### Gap G2 — Dead/dying models in production paths (Severity: CRITICAL, time-boxed)
- **Affected:** contextualization (already broken since Jun 1), answer generation (breaks Aug 16), all Groq judges/rerankers.
- **Root cause:** provider lifecycle; codebase mixes Gemini 2.0/2.5 and hardcodes Llama IDs.
- **Proposed fix:** Phase 0B-E (emergency) — provisional `gemini-3.6-flash`/`3.5-flash-lite`, `gpt-oss-120b`/`gpt-oss-20b`; Phase 0B-G — model registry + qualification.
- **Implemented:** NO.
- **Remaining risk:** Aug 16 Groq outage; ongoing silent contextualization failures since Jun 1.

### Gap G3 — Stale corpus + missing critical docs (Severity: HIGH)
- **Affected:** admissions/fee/merit answers.
- **Root cause:** no recent crawl; prospectus PDFs dead-lettered (HTTP 500 / timeout).
- **Proposed fix:** Phase 3 — quality-gated PDF re-ingestion with streaming/resume/parser-isolation (NOT lowered byte cap); incremental recrawl with tombstones.
- **Implemented:** NO.

### Gap G4 — Permissive prompt + unwired faithfulness judge (Severity: HIGH)
- **Affected:** hallucination risk on out-of-store topics.
- **Proposed fix:** Phase 6 — port rules from dead `prompts.ts` into live `prompt.ts`; strict abstain on empty/low-confidence context; wire `judgeFaithfulness` selectively (not every request).

### Gap G5 — Temporal/authority governance absent (Severity: HIGH, UET-specific)
- **Affected:** 2025 fee served for 2026 question.
- **Proposed fix:** Phase 2/3 — bitemporal metadata, version graph, temporal resolver (EXACTLY_APPLICABLE / HISTORICAL / SUPERSEDED / CONFLICTING), authority matrix.
