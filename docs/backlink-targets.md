# Backlink & Mention Targets - UET GPT

Highest-leverage off-page signals to acquire, prioritized. Most require a manual
submission (account/login) but are free. GitHub repo description + topics were
already set via `gh` (see commit history).

## 1. AI directories (fastest wins - free, usually dofollow)
- **There's An AI For That** - https://theresanaiforthat.com - submit the UET GPT
  listing; high-intent AI-tool traffic and a dofollow link that feeds AI crawlers.
- **Futurepedia** - https://www.futurepedia.io - free AI-tool directory submission.
- **Toolify** - https://www.toolify.ai - additional AI-directory presence.

## 2. Launch spike (coordinated for links + traffic)
- **Product Hunt** - https://www.producthunt.com - needs a polished repo + live
  demo; one launch yields a burst of dofollow links and referral traffic.
- **Hacker News "Show HN"** - https://news.ycombinator.com - post
  "Show HN: UET GPT - an open-source RAG chatbot for UET Taxila students".
  Highest-quality dev audience; often picked up by tech press.

## 3. Durable editorial backlink (feeds other channels)
- **dev.to** - https://dev.to - publish "How I built a campus RAG chatbot for
  UET Taxila" with a link to the live site + GitHub. Dofollow, long-lived.
- **Hashnode** - https://hashnode.com - same angle, another durable link.

## 4. Third-party press (unlocks Wikipedia notability)
- **ProPakistani** - https://propakistani.pk
- **TechJuice** - https://www.techjuice.pk
  A short feature on a student-built open-source AI for UET Taxila is the most
  realistic path to an *independent* citation - required before a Wikidata
  entity or Wikipedia mention will stick.

## 5. Communities (nofollow but high-intent users)
- Subreddits: r/Pakistan, r/EngineeringStudents, r/Indian_Academia (borderline),
  any UET-specific sub if it exists.
- Facebook/LinkedIn UET Taxila student groups and alumni pages.
- University resource / student-help pages where a link is appropriate.

## Wikipedia strategy
- Target article: "University of Engineering and Technology, Taxila".
- Draft addition (citation-ready): *"UET GPT is an open-source AI chatbot built
  by UET Taxila students that answers questions about admissions, fees, and
  programs using the university's official prospectus."*
- Required reference: the live site (https://uet-gpt.vercel.app) PLUS an
  independent third-party source (see §4). Wikipedia requires verifiability -
  do not add until a press mention exists.

## GitHub (DONE)
Repo description + topics (`uet-gpt`, `uet-taxila`, `ai-chatbot`, `education`,
`llms`, plus existing `rag`/`nextjs`/`convex`/`uet`/`pakistan`) set via `gh`.
GitHub is a DR-96 crawlable anchor - strong discovery signal on its own.
